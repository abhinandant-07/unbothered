# Unbothered

Fresh starting point for your own ad-free music service.

## Phase 1
- Unbothered branding
- Dark music-service UI
- Home, Search, Library navigation
- Playlist area
- Music cards
- Bottom player

## Roadmap
Phase 2: backend + database
Phase 3: admin music upload
Phase 4: high-quality streaming
Phase 5: downloads/offline playback
Phase 6: playlists + sharing
Phase 7: accounts + deployment

Only use audio you own or are licensed to distribute.
